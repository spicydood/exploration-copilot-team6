# Petroleum system and geological chance of success (GCoS)
- An opportunity needs four elements: reservoir, trap, seal and charge (source + migration).
- GCoS = P(reservoir) x P(trap) x P(seal) x P(charge); the weakest element dominates.
- Report the biggest risk element for every lead and the next data that would reduce it.
- Risked area = area x GCoS is a quick way to compare leads before volumetrics.
